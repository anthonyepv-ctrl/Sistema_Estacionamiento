# Auditoría Integral de Seguridad, Zonas Horarias y Estabilidad (Batalla de Errores)

Este documento registra los hallazgos, correcciones y casos de prueba ejecutados durante la auditoría intensiva de código sobre el Sistema de Gestión de Cochera, cubriendo backend, base de datos, frontend y pruebas automatizadas de extremo a extremo.

## 4. Guía de Desbloqueo de Culqi en Producción

El comercio Cochera SP (titular FLORES LEONARDO ALBERTH JAIR, RUC 10607991664) cuenta actualmente con llaves de integración en modo pruebas (DEVS). Para habilitar cobros reales en producción:

1. Verificar en Green (https://cochera-sp.onrender.com) que el pie de página muestre el titular y RUC, el modal de Términos y Política de Privacidad, la regla de adelanto mínimo S/ 3.00 para tarifas menores y el Libro de Reclamaciones Virtual operativo.
2. Ingresar al Panel de Culqi en la pestaña Panel de producción y completar los datos de validación del comercio (URL del sitio en producción, categoría Estacionamiento/Cochera, cuenta bancaria del titular RUC 10607991664 y copia de ficha RUC o DNI si lo solicita el formulario).
3. Si la revisión demora más de 48 horas hábiles, enviar correo a soporte@culqi.com o ticket desde el panel indicando el RUC, nombre del comercio, URL verificable y constancia del Libro de Reclamaciones Virtual activo.
4. Una vez emitidas las llaves live (pk_live_... y sk_live_...), actualizar la configuración desde el módulo Pasarela de Pagos Culqi del usuario DUEÑO y configurar CULQI_ENV=production en las variables de entorno de Render Green (manteniendo el ambiente Blue Staging con llaves de prueba).
