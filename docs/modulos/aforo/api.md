# Módulo Aforo / Espacios — Especificación de API (UPAO-11 / UPAO-49)

Ver referencia completa en: [`docs/modulos/espacios/api.md`](../espacios/api.md).

Endpoints:
- `GET /api/espacios`: Consulta de aforo y estado de espacios en tiempo real.
- `PUT /api/espacios/capacidad`: Configuración de capacidad máxima de autos y motos por el dueño.
